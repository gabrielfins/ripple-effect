Ripple Effect é uma biblioteca JavaScript leve para adicionar efeitos de ripple inspirados no Material Design a elementos do DOM, proporcionando interações visuais simples e personalizáveis.

Exemplos

Como usar

Use as classes abaixo para aplicar o efeito:

Classe Efeito
md-ripples Aplica o efeito ao elemento
ripples-light Define a cor do efeito para branco
ripples-dark Define a cor do efeito para preto

Mudando os padrões

Selecione a classe .ripple dentro da classe .md-ripples. Todos os elementos com a classe .md-ripples seguirão esse padrão. 


            .md-ripples .ripple {
              background-color: #a3eeff;
              opacity: .32;
            }

Classes personalizadas

Dê um nome à classe personalizada e selecione a classe .ripple dentro dela. 


            .ripples-purple .ripple {
              background-color: #e2a2ff;
              opacity: .32;
            }

Download

Baixe com:

npm install @gabrielfins/ripple-effect

Importe com:

import '@gabrielfins/ripple-effect';

Download manual

  1. Acesse o github arrow_outward do projeto
  2. Baixe a release mais recente
  3. Adicione o arquivo ripples.js da pasta /dist no seu projeto
  4. Importe o arquivo no seu HTML com: 
<script src="./your-path/ripples.js" defer></script>
