Ripple Effect

A Material Design ripple effect implementation created through reverse engineering using CSS and JavaScript, aiming to be as accurate as possible to the original effect.

Demo

How to use

The ripple effect is automatically enabled on all button elements. For other elements, you'll need to add the ripple attribute. Follow the guide below to learn more.

Attribute Effect
ripple Adds the ripple effect to non-button elements (buttons contains it by default)
no-ripple Disables the ripple effect on buttons
auto-ripple Makes all buttons inside this element automatically get ripple effects

Adding ripples to non-button elements

Add the 'ripple' attribute to enable ripples on non-button elements:

<a ripple href="#">Link with ripple</a>
Test here!

Customizing ripple color

Use the CSS variable --ripple-color on your element to set the desired ripple color. Here's an example:

<button style="--ripple-color: #21D4FD">Click me</button>

Disabling ripples

Add the no-ripple attribute to disable ripples on specific elements:

<button no-ripple>No ripple effect</button>

Add to project

You can install with npm

npm install @gabrielfins/ripple-effect

With yarn

yarn add @gabrielfins/ripple-effect

And import in your JavaScript file:

import '@gabrielfins/ripple-effect';

Or you can download and add the file to your project and import with the following tag:

<script src="ripples.js"></script>
